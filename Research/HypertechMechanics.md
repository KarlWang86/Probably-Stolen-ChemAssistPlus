# 超科技物品：获取与用途

整理日期：2026-11-13。

资料性质：本次玩家问答中查阅的社区 BWIKI 资料整理，尚未通过本机原生程序集 IL 或游戏内操作逐项验证。以下数值用于玩法参考，不作为已核实的原生 API 结论；游戏更新后以当前版本实际表现为准。

## 获取方式

1. 买下店铺产权后，乔·王尔德的人脉服务出现“高级”分页。
2. 购买“超科技走私贩”引荐，基础费用2500；购买后次日首次到访。
3. 后续通过夜间服务终端预约，基础费用500，次日上门，冷却5天；商品货款另付。
4. 每次来访随机带5件货。储藏区、心智重编程器、神经核心模组（无限制）每次各至多1件；电子元件、能源单元、涡轮增压器可重复出现。
5. 不能议价。供货商加价随难度变化，违禁品还会叠加相应加价。举报走私贩会关闭该夜间服务。

来源：[超科技走私贩](https://wiki.biligame.com/probablystolen/超科技走私贩)、[超科技机器](https://wiki.biligame.com/probablystolen/超科技机器)。

## 物品用途

| 物品 | 物品 ID | 作用与限制 |
| --- | --- | --- |
| 超科技能源单元 | `energy_credit_hyp` | 不储存电量，按额定输出持续供电。初始每周期输出12 kJ；机器耗电不超过额定输出时可持续运行，超过则完全不供电。每消耗1件电子元件（超科技），输出永久增加10 kJ，可反复升级。 |
| 超科技涡轮增压器 | `turbo_booster_hypertech` | 放入电源后，初始每周期耗电5 kJ、积累5点充能。每次消耗15点，使目标机器立即完成一轮运行，工具本体保留；剩余充能可继续累积。可消耗“高级涡轮增压器”升级，每次使周期充能与耗电各增加5。目标仍需满足原料、输出空间等条件，一轮结算不等于完成整份配方。 |
| 超科技储藏区 | `hypertech_bay` | 提供2个独立储物标签页，每页16×30格，共960格，可分别命名。只接受玩家拥有的物品，背包不能放入；其他储物容器是否可放入取决于嵌套规则。 |
| 电子元件（超科技） | `hypertech_electronic` | 消耗材料。用于能源单元时输出+10 kJ；用于心智重编程器时充能+1。每次消耗1件，两种用途均可反复投入；不同于普通电子元件。 |
| 心智重编程器 | `mind_reprogrammer` | 添加或移除部分开局特性。每件超科技电子元件提供1点充能；每次改写消耗对应特性点数，并冷却“点数×5天”。正面与中性特性可添加，负面特性只能移除；仅支持指定特性，并受互斥条件限制。装置不靠电力充能。 |
| 神经核心模组（无限制） | `system_uncapped_neural_core` | 通用机器模组：性能+200、效率−100、质量+100。提高加工速度与品质，但效率下降会显著增加耗电；属于4级高危违禁品。装入后需按机器实际功耗重新核对电源。 |

## 对化学机器的参考意义

- 多台机器长期运行时，可考虑为各台配置能源单元，并用超科技电子元件把输出提升至对应机器实际耗电以上。
- 使用无限制神经核心后，原有电源可能不再满足耗电条件，需要重新检查；不能仅凭“无限供电”判断可启动。
- 超科技涡轮增压器可重复使用，适合需要立即推进一轮加工的场景；具体化学机器能否接受加速，以及一轮如何结算，仍需定向核实。
