# 芬太片制作流程与自动化接入调查

日期：2026-11-13。范围仅为《Probably Stolen》游戏机制与本项目实现。

验证方式：只读核对本机原生程序集元数据/IL及当前源码；未启动游戏、未操作材料或存档、未新增/运行测试、未构建/部署/发布 mod。本报告的流程是据原生代码整理的方案，尚未游戏内验收。

本机 Assembly-CSharp.dll SHA256 与既有研究基线一致：`725CB999D019DFF1FF31BED353C7F9BB8D81A7605A15DE1F80F5A3A6CF7B1D05`。因此复用此前同哈希反应 IL，本轮补查拆包、稳定剂写入回调、液体属性及滤材孔径。

## 结论

推荐流程为：管制用品拆包 → 将前体液转入容量足够的工作瓶 → 常温处理稳定剂 → 按需处理剩余酸碱与杂质 → 加还原剂并控温反应 → 确认前体耗尽、检查残余试剂 → 除杂过滤/按需净化 → 原生过夜干燥（有挥发液时）→ 原生成型。

可以复用现有加热、过滤、转液、蒸发器分工和干料整理框架，但不是仅补一个前处理步骤：还涉及无挥发液批次入队、残余试剂、整数舍入尾量和完成判定。现阶段应称“局部扩展，需补齐流程边界”，不承诺已支持完整自动生产。

## 1. 原料与设备

- 原生 `RestrictedChemicalSupplies` 拆包销毁原包，生成两瓶前体和一瓶还原剂。这里只核实拆包内容，未重新调查供应商来访/出售概率。
- 每瓶前体初始加入 methylol 125 mL 与 stabilizing_agent 125 mL，随后用随机杂质替换部分内容。计算必须读取实际成分，不能把标称值当作现有有效量。
- 还原剂瓶初始为 reducing_agent 250 mL，随后同样加入随机杂质。
- 酸/碱来源、宽裕的工作瓶、可用加热板、过滤水罐和滤材；需要干燥时准备有电蒸发器。成型机的化学设备模组影响最终污染，不改变原生合成是否存在。
- 这是液体原料路线，不需要把整瓶当作固体搅拌。最小实现可由玩家先把前体液倒入搅拌机工作瓶，借用现有工作流入口；自动识别仓库前体瓶并取料属于另一个扩展目标。

证据：`fanta-supplies-unpack-20261113-il.txt`；`chem-prebuilt-il.txt` 的 CreateFantaPrecusorBottle、CreateReducingAgentBottle、SetImpurity。

## 2. 稳定剂必须先处理

原生可反应前体上限是 `max(0, methylol - stabilizing_agent)`；两者等量时不会合成。加水同时稀释两者，不能解除这一限制。

`HandleStabilizingAgentSedimentation` 不检查温度，可先在常温完成。酸或碱使稳定剂等体积变成 debris，并另行消耗酸/碱。它不是按稳定剂量等额扣除试剂。

每拍（单位 μL，以下 floor 表示正数转整）：

- `q = min(acid + base, stabilizing_agent)`；沉淀量 `n = min(q, max(1000, floor(q × 0.2)))`。
- 稳定剂减 n，debris 加 n。
- 酸损耗 `min(acid, max(100, floor(acid × 0.05)))`；碱同理。

完整原生反应调度还包含有机废物、微生物、蛋白等竞争反应，随后才进行酸碱中和。建议按已有净酸/净碱方向选择一种试剂，分次投料、观察稳定剂归零和真实耗量；不能把单独沉淀公式当作全瓶精确投料配方。

剩余酸碱不能靠普通滤材或蒸发去掉。可以依据实际净酸/净碱补相反试剂并调用原生中和，或在受控等待中继续观察消耗；中和时仍需考虑其它反应和来源杂质。稳定剂转出的 debris 可留到最终过滤，也可先过滤以减小后续占用；前置过滤会增加一次耗材/转液，需实现时选择，不应默认重复套用全套过滤。

证据：`chem-stabilizer-il.txt`；`fanta-stabilizer-callbacks-20261113-il.txt`；`chem-all-reactions-il.txt` 的 HandleTemperatureReaction、HandleAcidBaseNeutralization。

## 3. 加还原剂并控温合成

`HandleMethylolHeatReaction` 的有效温区：

| 液体实际温度 | 每拍基础比例 |
| --- | --- |
| 小于110℃ | 不反应 |
| 110℃至不足120℃ | 2.5% |
| 120℃至不足130℃ | 15% |
| 130℃及以上 | 不合成，已有产物还会热降解 |

现有 mod 的125℃目标位于较快温区。必须看工作瓶实际温度，不能只检查面板设定。

设 M 为前体、S 为稳定剂、R 为还原剂，每拍先取 `q = min(M - S, R)`，再取 `n = min(q, max(1000, floor(q × 比例)))`。实际更新：前体减 n；还原剂减 `Round(n × 0.75)`（下限0）；产物加 `Round(n × 0.1)`。这里是 .NET Math.Round 的原生规则，不能擅自换为固定向上取整。

**0.75是实际消耗系数，不等于每拍反应上限。** 原生先用剩余还原剂直接限制 q。现有一次性补足 `Ceiling((M-S)×0.75)` 的做法，应在实现时处理整数舍入导致的尾量；不能只凭累计理论比例宣称前体一定归零。也不宜直接大量过投，因为多余还原剂无法被现有过滤/蒸发清除。

温度达到130℃时，`HandleFantaHeat` 每拍把已有产物改为 `floor(原量 × 0.98)`。完成或异常后应关闭借用的加热板，恢复原目标；现有清理框架可复用。

证据：`chem-all-reactions-il.txt` 的 HandleMethylolHeatReaction、HandleFantaHeat；`chem-fanta-consumption-il.txt`。

## 4. 后处理与成型

本轮补查确认：fanta、methylol、reducing_agent、stabilizing_agent、acid、base 的粒径均为5，均未设置可挥发标记（默认false）；debris 粒径为200。滤布孔径150，普通/高级滤水器均为22。

原生滤材只有在孔径不大于该成分粒径时才执行截留。因此现有两级过滤可以处理 debris，不能把残余前体、稳定剂、还原剂或酸碱与有效产物分离。蒸发同样不能处理这些非挥发成分。UV/净水片分别针对微生物/化学污染，也不能当作上述试剂的通用去除手段。

后处理前应确认目标成分存在、前体及稳定剂确已处理，并显示残余试剂。残余过高时应报告原因并保料，不应将“没有进度”判作成功。过滤耐久不够也不能保证得到预期纯度。

有水等挥发成分时，沿用原生蒸发器过夜；若已满足原生干燥条件，则无需为了反应本身强制蒸发。`fanta_pill` 原生每件消耗500μL（0.5mL）**总干料**，要求 IsWet=false。干燥条件为所有可挥发成分合计不大于100μL，不是仅看有效成分纯度。成型仍引入与化学设备模组数相关的污染。

原料名义产率约10%，但每拍舍入、原料杂质、残余试剂、过滤与成型污染均影响实际产量/等级，不能按整瓶标称量保证成品件数。

证据：`fanta-liquid-definitions-20261113-il.txt`、`fanta-liquid-defaults-20261113-il.txt`、`fanta-filter-20261113-il.txt`、`fanta-filter-sizes-20261113-il.txt`；`chem-finisher-recipes-il.txt`；既有 `finisher-recipe-canoutput-il.txt`、`finisher-rules-20261112-il.txt`。

## 5. 当前 mod 的缺口与最小扩展范围

| 位置 | 当前行为 | 需要补齐 |
| --- | --- | --- |
| Core.cs / RecipeCatalog | 已列 fanta_pill，目标125℃ | 配方目录存在不等于流程完整 |

| BatchPlan.cs | 稳定剂≥前体且无产物时直接拦截 | 改为前处理需求；预算酸碱、真实来源杂质、峰值容量与滤材 |
| Workflow.cs / PrepareBatch | 先补反应物、加热，再通用去蛋白/脂肪 | 增加常温稳定剂处理及残余酸碱处理，之后再算还原剂 |
| Plus.cs / ReactableFeed、AlreadyExtracted | 以前体减稳定剂作为可反应量，且有产物即可视为已提取 | 禁止把“受稳定剂抑制但仍有前体”当作完成；加入残余成分判定 |
| Workflow.cs / 加热循环 | 可反应量归零或无进度时退出/报错 | 区分缺还原剂、稳定剂抑制、整数尾量与真正完成 |
| FilterPlan / Distillation | 通用过滤、蒸发、同类合并及干料入制剂机 | 可复用；进入后处理前先检查无法被滤除/蒸发的残余试剂 |

建议第一阶段：**玩家手动放前体工作瓶 → 结束当天进行原生前处理及合成 → 按需过滤/干燥 → 干料入制剂机，玩家手动成型。** 不在本阶段加入自动拆包、仓库取前体或自动压片。

待游戏内验证：正常原料整条链；已有部分产物但仍含稳定剂；试剂不足与来源不纯；容量不足；无挥发液原料入队；加热越界/中断；残余前体和还原剂尾量；滤材耐久不足；无空闲接收设备；干料手动成型后的实际纯度。本轮没有执行上述操作。
