# DNA填料草梦尘产线操作

目标：把梦帽浆生产特性装到填料草上，收获含梦帽浆的填料草，再接入现有化学助手的梦尘路线。先完成一次收获与配方识别，再考虑多年生。

## 1 准备底种和供电

- 留一颗普通填料草种子作备份，另取一颗用于编辑；用开启的基因扫描仪查看种子本体。
- 填料草自带简单基因组 II、高产 II、快速生长 II，第一轮不额外加高产。
- 准备备用梦帽菇种子、空白 DNA 数据盘和足够的电源。
- 此前第77天存档中，DNA编辑器的电源输出上限为10，机器基础需求为12。先更换电源；安装模组后，按机器显示的实际功耗重新核对输出和剩余能量。

## 2 获得梦帽浆生产盘

| 槽位 | 放置物品 |
| --- | --- |
| 目标槽 | 备用梦帽菇种子 |
| 输入盘槽 | 留空 |
| 输出盘槽 | 空白 DNA 数据盘 |

结束当天，等待编辑进度完成，可能需要多个晚上。查看盘上特性，确认得到“梦帽浆生产”。

空白盘提取默认随机；即使安装正面筛选模组，梦帽菇仍可能抽到多产种子，不能保证一次抽中梦帽浆生产。若已有梦帽浆生产盘，可放入输出盘槽定向提取并补充次数，输入盘槽继续留空。

**没有基因稳定模组时，无论提取成功还是失败，供体种子都会消失。只使用备用种。** 有稳定模组时保留供体，成功后对应特性降低一级。

## 3 安装到填料草

| 槽位 | 放置物品 |
| --- | --- |
| 目标槽 | 用于编辑的填料草种子 |
| 输入盘槽 | 梦帽浆生产盘 |
| 输出盘槽 | 留空 |

先关闭“保留数据盘”，结束当天并等待完成。成功后扫描种子，确认新增梦帽浆生产 I；一次成功安装只加一级并消耗盘的一次使用次数。

失败不扣盘次数，但成功和失败都会增加种子热度。第一轮只添加这一种路线的生产特性，不混装咖啡浆、咖啡因等其他生产特性。

## 4 种植并保留后代

将改良填料草种到准备好的水培机里，按植物提示准备水量和水质。先不安装会让填料草不产种子的增产专用模组。

收获后留取后代种子，用基因扫描仪确认继承了梦帽浆生产特性，且热度归零。留好改良种备份，再继续下一次编辑。

热度不会靠把原种放几天消除；繁殖得到的后代才会清除热度。

## 5 再决定是否添加多年生

若希望母株留在水培机里反复收获，可在已有备份后，给零热度的改良后代安装多年生 I。多年生带有减产、减速及减少种子产出的代价，先跑通基本产线再添加。

另一种方式是使用自动播种模组，收获后自动续种；首次换成改良填料草时，需人工确认实际续种的是改良种系。

**单纯换成填料草不会自动免除续种。** 第一次尝试可以暂时跳过本步，先完成第6步。

## 6 接入现有梦尘线

1. 将一份收获的改良填料草单独放进搅拌机输入格，准备工作瓶。
2. 按 F10 查看预检，确认显示梦尘路线、有效原料含量及预计耗料。
3. 预检通过后，再按现有化学助手用法开工。首次先做小批，观察日志与成品结果。

当前助手按原料实际成分识别路线，不限定原版梦帽菇名称；原料还必须具备原生可搅拌标签。含梦帽浆的改良填料草具备代码层面的接入条件，游戏内整条流程仍待本次实际验收。

当前使用限制：

- 普通填料草与改良填料草分批放，避免同物品 ID、不同成分混批。
- 一株只安装一种路线的生产特性。原料同时匹配多条路线时，当前代码取首个匹配配方，不会自动分离处理多条路线。
- 预检路线不对或提示原料不支持时，先停在预检，保留原料并记录面板提示。

本轮完成标准：收获含梦帽浆的填料草，留下一颗继承特性且热度归零的后代种子，并让 F10 正确识别梦尘路线。之后再验证实际加工与多年生循环。
