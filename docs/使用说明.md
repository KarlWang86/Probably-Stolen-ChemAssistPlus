# 化学流程助手 0.4.9

重启游戏后F10标题应为0.4.9。

## 快速开始

1. 咖啡豆、蘑菇等原料放入搅拌机；准备工作瓶、所需试剂、空闲加热器，以及空过滤水罐和滤芯或棉布。
2. 需要干燥的原液准备对应有电、容量足够的蒸发器；不同材料分别使用工作瓶和蒸发器。
3. 芬太片前体无需搅拌：将前体液装在容量足够的工作瓶内，直接放入关闭的加热器容器槽，前处理前冷却至110℃以下。
4. 按 F10 查看各台设备的预计用量和受阻原因，确认自动处理已开启。
5. 点击最终“结束当天”，助手先处理芬太加热器，再处理各台搅拌机。日间放料仅待命。
6. 次日查看处理结果；干料可能已转入制剂机，由玩家操作制剂。

## 自动处理步骤

以下是搅拌机原料路线；芬太片使用下方独立的加热器流程。

1. 原生搅拌，按真实浓度同比补充溶剂。
2. 原生 API 快速加热提取，去除蛋白和脂肪。
3. 单道过滤：优先滤芯，无可用滤芯时用棉布，每份原液只过滤一次。
4. 按需紫外线消毒，再按需投入净水药片。
5. 将原液交付对应蒸发器，继续原生过夜蒸发。

## 功能与使用规则

### 芬太片（加热器直接处理）

- 手动拆包并将前体液容器放入加热器槽；不需要搅拌，也不自动从仓库取前体。F10或加热器标题栏“化学助手”查看计划。无挥发液前体同样会入队。
- 加热器先关闭，前处理时保持低于110℃；助手处理稳定剂、蛋白/脂肪和残余酸碱后，在原位控温合成，结束或取消时关火并恢复原目标。
- 酸碱、还原剂及脂合剂按真实来源浓度同比转移，水和杂质一起进入。面板给出保守储备上限及峰值容量，并非承诺实际耗量；可能要求更大工作瓶。实际逐次投料，达到库存/容量/储备边界或无进展时保料停止。
- 只取不混有其他配方、稳定剂及无关反应试剂的来源；普通杂质保留同比进入。已有还原剂超过可无残余处理的保守范围时阻止开工，避免继续过投。
- 前体、稳定剂、还原剂、酸与碱均为0且有目标成分才视为完成；有少量产物不代表完成。这些残余无法靠现有过滤或蒸发清除，未通过检查时不移交。
- 沿用滤芯优先、棉布备用的单道过滤及按需净化。按净化后实际干湿分流：湿料送对应有电蒸发器原生过夜，干料可直接移瓶或整瓶转液至制剂机；没有合适接收位置时保留当前工作瓶并显示原因。成型由玩家操作。
- 每晚先按编号处理加热器，再按编号处理搅拌机，每台一次。完成的芬太瓶移出后，腾空的关闭加热器才可借给其他路线；助手不自动为加热器补瓶。

### 批次、投料与库存

- 默认自动开启，只在最终“结束当天”时开工，放料仅待命。

- 结束当天自动遍历所有搅拌机，每台每晚处理一批；逐批共用一台加热器和过滤设备，完成后关火移瓶，再处理下一台。
- 不同材料使用独立工作瓶及不同蒸发器。

- 只处理输入格第一种原料；酒精不足时只消耗能处理的整数份，剩余固体留格，不搅成余浆、不占备用容器。
- 不够一份则保留原料提示。

- 库存遍历包括前后台/储藏区/展示柜/垃圾箱等，以及背包、药片瓶、机器内部的嵌套物品；只使用玩家拥有的物品，含其他配方原料或产物的溶液不作试剂。

### 试剂浓度与用量换算

- 酒精每次优先当前浓度最高的来源，先用100%蒸馏酒精再用普通酒精；相同浓度优先续用旧瓶。
- 预检和投料均按有效酒精目标与当前真实浓度换算原溶液剂量，例如需要100mL有效酒精时，100%来源需100mL，70%来源约需142.858mL；混合来源逐瓶扣除。
- 其他试剂续用已选瓶直到耗尽；酸碱按实际净含量/当前浓度计算，无固定97%；所有水和杂质同比投入。

### 单道过滤

- 单道过滤优先使用可用滤芯，无可用滤芯时使用棉布，每份原液只过滤一次；滤芯耗尽后仅将尚未过滤的原液交给备用滤材。
- 棉布孔径较大，不能达到滤芯的精滤效果，使用时报告提示。
- 同类滤材优先选空水罐中已装好且有耐久的，再按最低正耐久选择；无可用组装时自动换装。
- 只需滤芯或棉布任一种可用，仍需要空过滤水罐及安全存放旧滤材的空间。

### 紫外线消毒

- 紫外线消毒在单道过滤后、净水药片前执行。
- 只要库存中有玩家拥有的紫外线灯且工作瓶还有微生物，就调用原生功能一次清除全部微生物，转为等体积水；不改变提取物、酒精或化学污染，无需电池、不耗灯的耐久。
- 没有灯则继续药片净化，无微生物则跳过；面板与日志记录结果或跳过原因。

### 净水药片

- 净水药片同时统计仓库散片与“一瓶净化药片”内的真实单片，优先散片，再用瓶内片，不把外瓶当一片。
- 在物理过滤后投入；原生要求有水，化学污染保留整瓶总体积0.7%的下限（包括酒精体积）。
- 低于下限且无微生物时投片不能继续净化，因此保留药片，报告显示实际污染量与下限；缺药片/瓶空间不足也提示。

### 蒸发器配方分工

- 蒸发器保留对应原液的配方记忆：优先沿用本配方设备，其次使用尚未分配的新设备，不自动借用已记其他配方的空机。
- 取走原液或只剩空瓶不清除记忆，游戏正常保存后重启仍保留。
- 首次启用按设备当前单一原液学习，无法追溯历史用途的空机在首次接收时分配；要手动调整用途，可把新的单一配方原液放进该台原液槽，助手轮询时按实际内容更新。
- 对应设备忙、缺电或装不下时提示并保留原料。
- 原液合并、同类存量集中与备用空瓶停放均遵守此分工；空置已分配蒸发器的机器窗口仍显示对应原料图标。
- 搅拌机仍处理玩家放入的原料，制剂机沿用原有同配方优先规则。

### 原液接收与同类合并

- 过滤后的新批次可直接倒入蒸发器原液槽的空接收瓶；合并后多出的空瓶可放入其他空闲原液槽备用，无空槽则留在搅拌机。
- 酒精回收槽及其中的瓶子保持原样，回收仍遵循原生模组和过夜规则。

- 同一种已提取湿半成品可以合并：有效成分占总体积的浓度差不超过5个百分点，接收瓶空间足够整批倒入且蒸发器有电时，优先倒入原液槽已有接收瓶。
- 槽内空瓶也可直接接收；不同配方、未提取原料、干燥成品、浓度差过大或容量不足不混入，改找空闲蒸发器。
- 产物从报告标注的蒸发器接收瓶取出，蒸干后可能自动移至制剂机。

- 合并预检按保守预计体积寻找同类接收瓶，净化后再按实际浓度、容量和供电复核；没有合格位置则保留本瓶原液，不强行倒入、不溢出或丢弃。

- 蒸发器产物仍在原液槽接收瓶（同类合并时是已有瓶）；馏出槽只回收溶剂。

### 设备不足时集中存量

- 当前批次没有可用蒸发器时，会先规划集中两台设备内同配方、已提取且仍湿的存量，允许浓度不同；必须整瓶装得下、两台有电且腾空的源瓶能接收下一批预计体积。
- 完整预检通过后才转液，源空瓶留在原液槽，再重新检查当前批次。
- 不同配方、未提取原料、干燥成品不集中；仍由原生过夜蒸发，集中后可能需要更久才能干燥。

- 无新原料或待提取原浆、蒸发器已有批次且无法同类合并时，正常等待并继续过夜，不提示占用错误。
- 有新原料时检查空槽或同类合并接收条件。

### 蒸干原液转入制剂机

- 自动处理开启时，过夜后及结束当天处理前会检查蒸发器：已提取、全部挥发液达到原生干燥容差的原液，优先整瓶并入已设同配方制剂机内的同类已提取干料，须接收瓶空间足够；源空瓶留蒸发器原液槽备用。
- 无法合并时，整瓶移入空闲制剂机，优先匹配已设同种制品，再选择未设置配方或其他空闲制剂机并设为对应配方。
- 不自动制剂；玩家在制剂机中操作。
- 没有合格位置时保留原瓶，不混湿料或不同配方。
- 日志和次日报告显示原蒸发器、制剂机、瓶号及合并体积。

### 过夜补瓶

- 过夜补瓶遵循“原空瓶优先，其次最大空瓶”：最终结束当天开工前记录每台搅拌机、蒸发器原液槽、制剂机当前容器编号，干料处理后和次日开始时补齐空槽。
- 先找回库存中可取用的原空瓶，再按容量选择最大的散放空瓶；当前槽内已有瓶子（包括空瓶）保留，有料瓶不转移，其他机器的瓶子与蒸发器回收槽不动。
- 没有可用空瓶就保留空槽，并写入日志／结果。
- 不创建瓶子或倒空材料。
- 制剂机已有空接收瓶且装得下时，可将蒸干原液整瓶转入其中，源空瓶留蒸发器备用。
- 遵循自动处理开关，日间放料不触发补瓶。

### 手动倒液确认

- 手动原生倒液时，会检查原材料加工出的原浆、中间液和提取物：不同配方相混，或同配方原浆／提取物合计占总体积的百分比相差超过5个百分点，或一瓶已蒸干、另一瓶仍含挥发液，都会先弹“原液混合确认”。
- 显示来源瓶、接收瓶、配方成分、占比和挥发液；“确定混合”执行原生倒液，“取消”不转液。
- 只检查原材料加工出的成分，酒精、水、酸碱等溶剂／试剂本身不触发；空瓶接液不提示。
- 确认期间瓶子移动、成分变化或切档会取消本次授权，请重新倒液确认。
- 自动加工的同类合并限制保持不变。

- 混液确认正文固定大字号，集中显示触发原因、两瓶编号、成分占比及剩余挥发液；超长内容可滚动，确认／取消按钮留在底部。
- 提示框关闭或被其他原生对话框替换后恢复原生布局。
- 图标直接读取实际液体组分，倒液、换槽后刷新；空蒸发器的原料图标仍表示已记住的设备分工。

### 原材料图标

- 液体容器在瓶身中间显示原材料图标，多种纵向排列；库存和机器操作窗口容器槽里的瓶子采用相同规则。
- 机器本体左上角按原液／工作瓶内的实际成分横向显示，右上角留给其他模组状态；操作窗口标题栏不放原料图标。
- 按原生图片实际显示边界和槽位遮罩定位／缩放，保留旋转、翻转和拖影同步。
- 咖啡浆／咖啡因显示咖啡豆，梦帽菇浆／萃取液和其衍生奥克莫吸显示梦帽菇，梦魇帽菇浆／萃取液显示梦魇帽菇。
- 同一原料多个阶段只显示一个图标；水、酒精、酸碱等试剂及没有明确原材料映射的成分不显示。
- 图标随转液、换瓶、倒空刷新，不影响鼠标操作和配方规则。

### F10 用量、结果与通知

- 面板“当前用量”显示全部搅拌机独立预估，“本晚结果”显示各批实际耗料及已完成阶段。
- 工作瓶装不下整批时自动缩减整份原料，余料留输入格；一份仍放不下才提示换大瓶。

- 当前用量和本晚结果按设备显示条形行：名称靠左，条内显示“预计用量 / 当前库存”或“实际用量 / 开工库存”；处理结果条内显示“剂量 / 纯度”。
- 试剂条按用量占库存填充，处理结果条按纯度填充。
- 未实际使用紫外线或净水药片时，本晚结果不列对应说明，详细原因仍可查日志。

- 面板450x600、3:4竖版。
- 溶剂每项名称/短条/原溶液使用与库存，药片按片；预计和实际分开标示。
- 五阶段每行总剂量/纯度，未执行显示待处理。

- 底部自动处理、次日弹窗、刷新、关闭并排；成型入口隐藏，接口保留。

- 当晚不弹F10；实际处理过且次日弹窗开启才翌日显示。
- 供电小通知独立于次日F10开关。
- 受阻原因可手动F10查看。

### 进度条颜色

- 进度条采用pH指示剂参考色：咖啡浆橙黄（参考咖啡萃取液pH4.85–5.13）、咖啡因黄绿（参考10g/L水溶液25°C下pH5.5–6.5）、纯水绿（25°C下pH7）；酸液红橙、碱液蓝紫仅表示分类。
- 酒精及未知/配方不明成分用灰色。
- 颜色参考主要成分的文献条件，不代表游戏混合液或干料的实测pH；库存不足时名称标红。

### 供电提醒与异常处理

- 有湿料但缺电池/电量不足，F10持续显示原因与瓶号，每天开始另有游戏小通知；无需新搅拌任务也检查，补电后清除。
- 不自动换电池。

- 每批开工前重新检查当前库存和设备；条件不足时保留该台原料，继续检查下一台。
- 执行中异常则停止剩余队列、关火保液并恢复过夜。
- 次日报告文字汇总各台结果、产品、蒸发器及工作瓶编号；剂量条和五阶段成分条显示最后一批详情。

- 失败保留剩余物料并续原生过夜，开关保持开启；手动关闭停止任务，切档清旧任务并默认开启。
